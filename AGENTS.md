# Instructions for agents

This is the setup repo for a personal ontology vault. It is not the vault. If someone gave you this repo or its link, they want you to build their vault.

1. Clone the repo if you have not already, and read `SETUP.md` in full.
2. Work out which harness you are running in (Claude Code, Codex CLI, Gemini CLI, or another), and follow the harness table in `SETUP.md`.
3. Follow `SETUP.md` step by step. Ask one question at a time, get approval at each gate, and show the owner each command that edits their settings before you run it.
4. Copy files out of `template/` into the owner's new vault. Never edit them in place here.
