# Personal ontology vault

The owner's private, git-backed knowledge base, read and grown by their Claude sessions and agents.

## Details

- It lives in Obsidian and a private GitHub repo. Agents pull it at the start of a session and capture durable facts into it as they come up.[^1]
- Articles are grouped by topic. Each topic is a hub listed in [[Vault topics]].[^1]
